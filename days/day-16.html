Taylor and Maclaurin Series

Problem 1: Maclaurin Series for sin(x)

Task: Find the Maclaurin series for f(x) = sin(x).

Click to see the solution

Step 1: Compute derivatives at x = 0

f(x) = sin(x), f(0) = 0

f'(x) = cos(x), f'(0) = 1

f''(x) = -sin(x), f''(0) = 0

f'''(x) = -cos(x), f'''(0) = -1

f^(4)(x) = sin(x), f^(4)(0) = 0

The pattern repeats every 4 derivatives.

Step 2: Write the series

f(x) = sum from n=0 to infinity of f^(n)(0)/n! * x^n

= 0 + x - x^3/3! + x^5/5! - x^7/7! + ...

Final Answer:

sin(x) = sum from n=0 to infinity of (-1)^n * x^(2n+1)/(2n+1)!

Problem 2: Maclaurin Series for e^x

Task: Find the Maclaurin series for f(x) = e^x.

Click to see the solution

Step 1: Compute derivatives

f(x) = e^x, f'(x) = e^x, f''(x) = e^x, ...

All derivatives at x = 0: f^(n)(0) = e^0 = 1

Step 2: Write the series

e^x = sum from n=0 to infinity of x^n/n!

= 1 + x + x^2/2! + x^3/3! + x^4/4! + ...

Final Answer:

e^x = sum from n=0 to infinity of x^n/n!

Problem 3: Maclaurin Series for cos(x)

Task: Find the Maclaurin series for f(x) = cos(x).

Click to see the solution

Step 1: Compute derivatives at x = 0

f(x) = cos(x), f(0) = 1

f'(x) = -sin(x), f'(0) = 0

f''(x) = -cos(x), f''(0) = -1

f'''(x) = sin(x), f'''(0) = 0

f^(4)(x) = cos(x), f^(4)(0) = 1

Step 2: Write the series

cos(x) = 1 - x^2/2! + x^4/4! - x^6/6! + ...

Final Answer:

cos(x) = sum from n=0 to infinity of (-1)^n * x^(2n)/(2n)!
