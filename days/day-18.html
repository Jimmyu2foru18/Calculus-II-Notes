Parametric Equations and Polar Areas

Problem 1: Parametric Equations

Task: Find the parametric equations for the parabola y = x^2 + 3x - 4.

Click to see the solution

Step 1: Choose a parameter

Let x = t.

Step 2: Express y in terms of t

y = t^2 + 3t - 4

Final Answer:

x(t) = t, y(t) = t^2 + 3t - 4

Problem 2: Arc Length of a Parametric Curve

Task: Find the arc length of the curve x = t, y = t^2 from t = 0 to t = 1.

Click to see the solution

Step 1: Use the arc length formula

L = integral from a to b of sqrt((dx/dt)^2 + (dy/dt)^2) dt

Step 2: Compute derivatives

dx/dt = 1, dy/dt = 2t

Step 3: Set up the integral

L = integral from 0 to 1 of sqrt(1 + (2t)^2) dt

= integral from 0 to 1 of sqrt(1 + 4t^2) dt

Step 4: Use trigonometric substitution

Let 2t = tan(theta), then dt = (1/2)*sec^2(theta) d(theta)

When t = 0, theta = 0. When t = 1, theta = arctan(2).

sqrt(1 + 4t^2) = sqrt(1 + tan^2(theta)) = sec(theta)

L = integral from 0 to arctan(2) of sec(theta) * (1/2)*sec^2(theta) d(theta)

= (1/2) * integral from 0 to arctan(2) of sec^3(theta) d(theta)

This requires integration by parts, giving:

L = (1/2)[sec(theta)*tan(theta) + ln|sec(theta) + tan(theta)|] from 0 to arctan(2)

Final Answer:

L = (1/2)[2*sqrt(5) + ln(2 + sqrt(5))]

Problem 3: Area in Polar Coordinates

Task: Find the area inside the cardioid r = 1 + cos(theta).

Click to see the solution

Step 1: Set up the area integral

A = (1/2) * integral from 0 to 2*pi of (1 + cos(theta))^2 d(theta)

Step 2: Expand the integrand

(1 + cos(theta))^2 = 1 + 2*cos(theta) + cos^2(theta)

= 1 + 2*cos(theta) + (1 + cos(2*theta))/2

= 3/2 + 2*cos(theta) + (1/2)*cos(2*theta)

Step 3: Integrate

A = (1/2) * integral from 0 to 2*pi of [3/2 + 2*cos(theta) + (1/2)*cos(2*theta)] d(theta)

= (1/2) * [3*theta/2 + 2*sin(theta) + (1/4)*sin(2*theta)] from 0 to 2*pi

= (1/2) * [(3*pi) + 0 + 0 - 0]

= (1/2) * 3*pi = 3*pi/2

Final Answer:

The area is 3*pi/2.
