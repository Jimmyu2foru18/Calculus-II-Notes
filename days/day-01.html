Calculus I Review: Derivatives

Key Concept — The Derivative

The derivative of a function measures the instantaneous rate of change. Geometrically, it represents the slope of the tangent line at any point on the curve.

$$f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$$

Example: For $f(x) = x^2$, the derivative is $f'(x) = 2x$.

Figure 1.1 — Derivative as Slope of Tangent Line

The derivative $f'(x)$ gives the slope of the tangent line to the curve $y = f(x)$ at any point $x$.

Derivative Rules

Basic Differentiation Rules

Power Rule: $\frac{d}{dx}[x^n] = nx^{n-1}$

Constant Rule: $\frac{d}{dx}[c] = 0$

Sum/Difference Rule: $\frac{d}{dx}[f(x) \pm g(x)] = f'(x) \pm g'(x)$

Exponential: $\frac{d}{dx}[e^x] = e^x$

Logarithmic: $\frac{d}{dx}[\ln x] = \frac{1}{x}$

Worked Examples

Example 1.1 — Power and Constant Rules

Find $f'(x)$ for $f(x) = 7x^3 - 2x + 5$:

$$f'(x) = 7(3x^2) - 2(1) + 0 = 21x^2 - 2$$

Example 1.2 — Chain Rule

Find $f'(x)$ for $f(x) = e^{x^2+1}$:

$$f'(x) = e^{x^2+1} \cdot (2x + 0) = 2xe^{x^2+1}$$

The Chain Rule is applied separately to each composite term.

Example 1.3 — Product Rule

Find $f'(x)$ for $f(x) = e^x \sin(x^2)$:

$$f'(x) = e^x \cdot \sin(x^2) + e^x \cdot \cos(x^2) \cdot 2x$$

Using the Product Rule: $(fg)' = f'g + fg'$

Calculus I Review: Anti-derivatives

Key Concept — Anti-derivatives

An anti-derivative of $f(x)$ is a function $F(x)$ such that $F'(x) = f(x)$. The indefinite integral represents the family of all anti-derivatives:

$$\int f(x) \, dx = F(x) + C$$

where $C$ is the constant of integration.

Basic Integration Rules

Fundamental Integration Formulas

$\int x^n \, dx = \frac{x^{n+1}}{n+1} + C, \quad n \neq -1$

$\int e^x \, dx = e^x + C$

$\int \frac{1}{x} \, dx = \ln|x| + C$

$\int \sin x \, dx = -\cos x + C$

$\int \cos x \, dx = \sin x + C$

$\int \sec^2 x \, dx = \tan x + C$

$\int \csc^2 x \, dx = -\cot x + C$

$\int \sec x \tan x \, dx = \sec x + C$

$\int \csc x \cot x \, dx = -\csc x + C$

$\int \frac{1}{\sqrt{1-x^2}} \, dx = \arcsin x + C$

$\int \frac{1}{1+x^2} \, dx = \arctan x + C$

Worked Examples

Example 1.4 — Polynomial Integration

Find: $\displaystyle\int (x^2 - 5 + 7x^{-1} + 8x^{-2}) \, dx$

$$\int (x^2 - 5 + 7x^{-1} + 8x^{-2}) \, dx = \frac{x^3}{3} - 5x + 7\ln|x| - 8x^{-1} + C$$

Example 1.5 — Expanding and Integrating

Find: $\displaystyle\int (x+1)^2 \, dx$

$$\int (x^2 + 2x + 1) \, dx = \frac{x^3}{3} + x^2 + x + C$$

Example 1.6 — Trigonometric Integration

Find: $\displaystyle\int \left(4(1+x^2)^{-1} + \sec^2 x\right) dx$

$$\int \frac{4}{1+x^2} \, dx + \int \sec^2 x \, dx = 4\arctan x + \tan x + C$$

Calculus II Course Overview

Topics Covered in Calculus II

Calculus II builds on the foundation of Calculus I and covers four major areas:

1. Techniques of Integration

  • u-Substitution: Change variables to simplify integrals
  • Integration by Parts: $\int u \, dv = uv - \int v \, du$ for products
  • Trigonometric Substitution: Use identities to replace variables with trigonometric expressions
  • Partial Fraction Decomposition: Break down rational functions into simpler fractions

2. Applications of Integrals

  • Area Between Curves: $A = \int_a^b [f(x) - g(x)] \, dx$
  • Volumes of Solids of Revolution: Disk and shell methods
  • Arc Length: $L = \int_a^b \sqrt{1 + [f'(x)]^2} \, dx$
  • Work: Total work done by variable force over displacement

Figure 1.2 — Area Between Curves

The area between two curves $f(x)$ and $g(x)$ from $x=a$ to $x=b$ is given by the integral of the upper curve minus the lower curve.

3. Sequences and Series

  • Sequences: Ordered lists of numbers that may converge to a finite limit
  • Series: The infinite summation of terms of a sequence
  • Convergence Tests: Divergence Test, Integral Test, p-Series Test, Comparison Tests
  • L'Hôpital's Rule: Evaluate indeterminate forms

Figure 1.3 — Convergent vs. Divergent Series

A convergent sequence approaches a finite limit $L$ as $n \to \infty$. A divergent sequence does not approach any finite limit.

4. Parametric Equations and Polar Coordinates

  • Parametrization: Express $x$ and $y$ as functions of parameter $t$
  • Derivatives: $\frac{dy}{dx} = \frac{dy/dt}{dx/dt}$
  • Arc Length: $L = \int_a^b \sqrt{\left(\frac{dx}{dt}\right)^2 + \left(\frac{dy}{dt}\right)^2} \, dt$
  • Area: $A = \int_a^b y \, dx$ for parametric curves

Integration by Substitution

The Substitution Method

Integration by substitution reverses the chain rule. If $u = g(x)$, then $du = g'(x) \, dx$, and:

$$\int f(g(x)) \cdot g'(x) \, dx = \int f(u) \, du$$

The goal is to transform the integral into an easier form by choosing an appropriate substitution.

Worked Examples

Example 1.7 — Basic Substitution

Evaluate: $\displaystyle\int e^{7x} \, dx$

Let $u = 7x$, then $du = 7 \, dx$, so $dx = \frac{du}{7}$:

$$\int e^{7x} \, dx = \int e^u \cdot \frac{du}{7} = \frac{1}{7}e^u + C = \frac{1}{7}e^{7x} + C$$

Example 1.8 — Polynomial Substitution

Evaluate: $\displaystyle\int (x+1)^3 \cdot 4x^3 \, dx$

Let $u = x+1$, then $du = dx$ and $x = u-1$:

$$\int (u-1)u^3 \, du = \int (u^4 - u^3) \, du = \frac{u^5}{5} - \frac{u^4}{4} + C = \frac{(x+1)^5}{5} - \frac{(x+1)^4}{4} + C$$

Example 1.9 — Rational Function Substitution

Evaluate: $\displaystyle\int \frac{x^3}{1+x^4} \, dx$

Let $u = 1+x^4$, then $du = 4x^3 \, dx$, so $x^3 \, dx = \frac{du}{4}$:

$$\int \frac{x^3}{1+x^4} \, dx = \int \frac{1}{u} \cdot \frac{du}{4} = \frac{1}{4}\ln|u| + C = \frac{1}{4}\ln|1+x^4| + C$$

Example 1.10 — Arctangent Substitution

Evaluate: $\displaystyle\int \frac{dx}{1+x^2}$

Let $u = x^2$, then $du = 2x \, dx$:

$$\int \frac{dx}{1+x^2} = \arctan x + C$$

Example 1.11 — Sine Substitution

Evaluate: $\displaystyle\int \sin(5x) \, dx$

Let $u = 5x$, then $du = 5 \, dx$:

$$\int \sin(5x) \, dx = \int \sin(u) \cdot \frac{du}{5} = -\frac{1}{5}\cos(u) + C = -\frac{1}{5}\cos(5x) + C$$

Example 1.12 — Power Substitution

Evaluate: $\displaystyle\int \frac{x^2}{\sqrt{x^5+1}} \, dx$

Let $u = x^5+1$, then $du = 5x^4 \, dx$:

$$\int x^2 \cdot u^{-1/2} \, dx = \frac{1}{5}\int u^{-1/2} \, du = \frac{2}{5}u^{1/2} + C = \frac{2\sqrt{x^5+1}}{5} + C$$

Example 1.13 — Inverse Trigonometric Substitution

Evaluate: $\displaystyle\int \frac{x^2}{\sqrt{1-x^4}} \, dx$

Let $u = x^2$, then $du = 2x \, dx$:

$$\int \frac{x}{\sqrt{1-u^2}} \, du = \frac{1}{2}\arcsin(u) + C = \frac{1}{2}\arcsin(x^2) + C$$

Example 1.14 — Composite Function Substitution

Evaluate: $\displaystyle\int \cos(\sec x) \cdot \sec x \tan x \, dx$

Let $u = \sec x$, then $du = \sec x \tan x \, dx$:

$$\int \cos(\sec x) \cdot \sec x \tan x \, dx = \int \cos(u) \, du = \sin(u) + C = \sin(\sec x) + C$$

Practice Problems

Exercises — Integration by Substitution

Problem 1 — Basic Substitution

Evaluate: $\displaystyle\int e^{7x} \, dx$

Answer: Let $u = 7x$, $du = 7 \, dx$. Then $\int e^{7x} \, dx = \frac{1}{7}e^{7x} + C$.

Problem 2 — Polynomial Substitution

Evaluate: $\displaystyle\int (x+1)^3 \cdot 4x^3 \, dx$

Answer: Let $u = x+1$, then $x = u-1$. Expand and integrate: $\frac{(x+1)^5}{5} - \frac{(x+1)^4}{4} + C$.

Problem 3 — Logarithmic Substitution

Evaluate: $\displaystyle\int \frac{x^3}{1+x^4} \, dx$

Answer: Let $u = 1+x^4$, $du = 4x^3 \, dx$. Then $\frac{1}{4}\ln|1+x^4| + C$.

Problem 4 — Arctangent Form

Evaluate: $\displaystyle\int \frac{dx}{1+x^2}$

Answer: $\arctan x + C$.

Problem 5 — Sine Substitution

Evaluate: $\displaystyle\int \sin(5x) \, dx$

Answer: Let $u = 5x$, $du = 5 \, dx$. Then $-\frac{1}{5}\cos(5x) + C$.

Problem 6 — Power Function Substitution

Evaluate: $\displaystyle\int \frac{x^2}{\sqrt{x^5+1}} \, dx$

Answer: Let $u = x^5+1$, $du = 5x^4 \, dx$. Then $\frac{2\sqrt{x^5+1}}{5} + C$.

Study Tips

1. Choose $u$ wisely: Pick $u$ to be the inner function whose derivative appears elsewhere in the integrand.

2. Check your substitution: After substituting, every part of the integral should be in terms of $u$ and $du$. If $x$ or $dx$ remains, the substitution is incomplete.

3. Don't forget the constant: Always add $+C$ for indefinite integrals.

4. Practice the pattern: Most substitution problems follow the pattern $\int f(g(x))g'(x)\,dx = \int f(u)\,du$.
