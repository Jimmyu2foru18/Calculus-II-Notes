Partial Fractions Decomposition

Partial fractions decomposition breaks a rational function into a sum of simpler fractions that are easier to integrate. The method depends on the factorization of the denominator.

Partial Fractions Rules

Distinct linear factors: For each factor $(x - r)$, include a term $\frac{A}{x - r}$.

Repeated linear factors: For $(x - r)^k$, include $\frac{A_1}{x - r} + \frac{A_2}{(x - r)^2} + \cdots + \frac{A_k}{(x - r)^k}$.

Irreducible quadratic factors: For $ax^2 + bx + c$, include $\frac{Ax + B}{ax^2 + bx + c}$.

Repeated irreducible quadratics: Include terms with numerators linear in $x$ for each power.

Example 1.1

Problem: Decompose $\displaystyle \frac{3x + 5}{x^2 - 4}$ into partial fractions.

Figure — Partial fractions decomposition regions

The denominator $x^2-4 = (x+2)(x-2)$ creates vertical asymptotes at $x = \pm 2$.

Click to see the solution

Step 1:

Factor the denominator: $x^2 - 4 = (x + 2)(x - 2)$.

Step 2:

Set up the decomposition with distinct linear factors:

$$\frac{3x + 5}{(x + 2)(x - 2)} = \frac{A}{x + 2} + \frac{B}{x - 2}$$

Step 3:

Clear denominators by multiplying through:

$$3x + 5 = A(x - 2) + B(x + 2)$$

Step 4:

Solve for $A$ and $B$ using strategic substitutions:

Set $x = 2$: $3(2) + 5 = A(0) + B(4) \Rightarrow 11 = 4B \Rightarrow B = \frac{11}{4}$

Set $x = -2$: $3(-2) + 5 = A(-4) + B(0) \Rightarrow -1 = -4A \Rightarrow A = \frac{1}{4}$

Final Answer:

$$\frac{3x + 5}{x^2 - 4} = \frac{1}{4(x + 2)} + \frac{11}{4(x - 2)}$$

Example 1.2

Problem: Decompose $\displaystyle \frac{x^2 + 3x + 2}{(x + 1)^3}$ into partial fractions.

Click to see the solution

Step 1:

Identify the repeated linear factor $(x + 1)^3$. Set up the decomposition:

$$\frac{x^2 + 3x + 2}{(x + 1)^3} = \frac{A}{x + 1} + \frac{B}{(x + 1)^2} + \frac{C}{(x + 1)^3}$$

Step 2:

Clear denominators:

$$x^2 + 3x + 2 = A(x + 1)^2 + B(x + 1) + C$$

Step 3:

Expand the right side:

$$x^2 + 3x + 2 = A(x^2 + 2x + 1) + Bx + B + C$$ $$= Ax^2 + (2A + B)x + (A + B + C)$$

Step 4:

Match coefficients:

$$A = 1, \quad 2A + B = 3 \Rightarrow B = 1, \quad A + B + C = 2 \Rightarrow C = 0$$

Final Answer:

$$\frac{x^2 + 3x + 2}{(x + 1)^3} = \frac{1}{x + 1} + \frac{1}{(x + 1)^2}$$

Trigonometric Substitution

Trigonometric substitution is used for integrals containing $\sqrt{a^2 - x^2}$, $\sqrt{a^2 + x^2}$, or $\sqrt{x^2 - a^2}$. The substitution simplifies the radical using trigonometric identities.

Trig Substitution Reference

FormSubstitutionIdentity Used
$\sqrt{a^2 - x^2}$$x = a\sin(\theta)$$1 - \sin^2(\theta) = \cos^2(\theta)$
$\sqrt{a^2 + x^2}$$x = a\tan(\theta)$$1 + \tan^2(\theta) = \sec^2(\theta)$
$\sqrt{x^2 - a^2}$$x = a\sec(\theta)$$\sec^2(\theta) - 1 = \tan^2(\theta)$

Example 2.1

Problem: Evaluate $\displaystyle \int \frac{dx}{\sqrt{9 + 4x^2}}$.

Figure — Trig substitution setup for $\sqrt{9+4x^2}$

The right triangle for back-substitution uses $2x = 3\tan\theta$ to eliminate the radical.

Click to see the solution

Step 1:

Identify the form $\sqrt{a^2 + x^2}$ with $a = 3$ (note: $4x^2 = (2x)^2$). Use $2x = 3\tan(\theta)$, so $x = \frac{3}{2}\tan(\theta)$:

$$dx = \frac{3}{2}\sec^2(\theta)\,d\theta$$

Step 2:

Simplify the radical:

$$\sqrt{9 + 4x^2} = \sqrt{9 + 4 \cdot \frac{9}{4}\tan^2(\theta)} = \sqrt{9(1 + \tan^2(\theta))} = 3\sec(\theta)$$

Step 3:

Substitute into the integral:

$$\int \frac{dx}{\sqrt{9 + 4x^2}} = \int \frac{\frac{3}{2}\sec^2(\theta)\,d\theta}{3\sec(\theta)} = \frac{1}{2}\int \sec(\theta)\,d\theta$$

Step 4:

Evaluate the integral and back-substitute. From $x = \frac{3}{2}\tan(\theta)$, we have $\tan(\theta) = \frac{2x}{3}$ and $\sec(\theta) = \frac{\sqrt{9 + 4x^2}}{3}$:

$$\frac{1}{2}\ln|\sec(\theta) + \tan(\theta)| + C = \frac{1}{2}\ln\left|\frac{\sqrt{9 + 4x^2} + 2x}{3}\right| + C$$

Final Answer:

$$\int \frac{dx}{\sqrt{9 + 4x^2}} = \frac{1}{2}\ln|\sqrt{9 + 4x^2} + 2x| + C$$

Example 2.2

Problem: Evaluate $\displaystyle \int \frac{x^3\,dx}{\sqrt{4 - x^2}}$.

Click to see the solution

Step 1:

Use $x = 2\sin(\theta)$, $dx = 2\cos(\theta)\,d\theta$, and $\sqrt{4 - x^2} = 2\cos(\theta)$:

$$\int \frac{x^3\,dx}{\sqrt{4 - x^2}} = \int \frac{(2\sin(\theta))^3 \cdot 2\cos(\theta)\,d\theta}{2\cos(\theta)} = \int 8\sin^3(\theta)\,d\theta$$

Step 2:

Use the identity $\sin^2(\theta) = 1 - \cos^2(\theta)$:

$$8\int \sin^3(\theta)\,d\theta = 8\int (1 - \cos^2(\theta))\sin(\theta)\,d\theta$$

Step 3:

Use substitution $u = \cos(\theta)$, $du = -\sin(\theta)\,d\theta$:

$$= 8\int (1 - u^2)(-du) = 8\int (u^2 - 1)\,du = 8\left(\frac{u^3}{3} - u\right) + C$$

Step 4:

Back-substitute using $\cos(\theta) = \frac{\sqrt{4 - x^2}}{2}$:

$$= \frac{8}{3}\left(\frac{\sqrt{4 - x^2}}{2}\right)^3 - 8 \cdot \frac{\sqrt{4 - x^2}}{2} + C = \frac{(4 - x^2)^{3/2}}{3} - 4\sqrt{4 - x^2} + C$$

Final Answer:

$$\int \frac{x^3\,dx}{\sqrt{4 - x^2}} = \frac{(4 - x^2)^{3/2}}{3} - 4\sqrt{4 - x^2} + C$$

Comparing Integration Techniques

Choosing the right technique is critical. Use this decision tree: first try substitution, then integration by parts, then trig substitution, then partial fractions.

Integration Strategy Guide

1. Simplify the integrand algebraically before choosing a method.

2. Substitution: Look for a function and its derivative in the integrand.

3. Integration by parts: Useful for products of algebraic and transcendental functions: $\int u\,dv = uv - \int v\,du$.

4. Trigonometric substitution: Use when radicals of the form $\sqrt{a^2 \pm x^2}$ or $\sqrt{x^2 - a^2}$ appear.

5. Partial fractions: Apply to rational functions $\frac{P(x)}{Q(x)}$ where $\deg(P) < \deg(Q)$.

6. If nothing works: Consider rewriting the integrand using identities or splitting into pieces.

Example 3.1

Problem: Evaluate $\displaystyle \int x\cos(x^2)\,dx$ by selecting the best method.

Click to see the solution

Step 1:

Identify the structure: we have $x$ multiplied by $\cos(x^2)$. Notice that $\frac{d}{dx}(x^2) = 2x$, so the derivative of the inner function is present (up to a constant). This suggests substitution.

Step 2:

Use substitution: let $u = x^2$, $du = 2x\,dx$:

$$\int x\cos(x^2)\,dx = \frac{1}{2}\int \cos(u)\,du = \frac{1}{2}\sin(u) + C$$

Final Answer:

$$\int x\cos(x^2)\,dx = \frac{1}{2}\sin(x^2) + C$$

Practice Problems

Problem 1 — Decompose $\displaystyle \frac{2x - 1}{x^2 - 5x + 6}$

Factor the denominator and find the partial fraction decomposition.

Show Answer

Answer:

Factor: $x^2 - 5x + 6 = (x - 2)(x - 3)$. The decomposition is:

$$\frac{2x - 1}{x^2 - 5x + 6} = \frac{3}{x - 2} - \frac{1}{x - 3}$$
Problem 2 — Evaluate $\displaystyle \int \frac{dx}{x^2\sqrt{4 - x^2}}$

Use trigonometric substitution to evaluate the integral.

Show Answer

Answer:

Use $x = 2\sin(\theta)$. The result is:

$$\int \frac{dx}{x^2\sqrt{4 - x^2}} = -\frac{\sqrt{4 - x^2}}{4x} + C$$
Problem 3 — Evaluate $\displaystyle \int x e^{3x}\,dx$

Choose the best integration technique and evaluate.

Show Answer

Answer:

Use integration by parts with $u = x$, $dv = e^{3x}\,dx$:

$$\int x e^{3x}\,dx = \frac{x e^{3x}}{3} - \frac{e^{3x}}{9} + C = \frac{e^{3x}(3x - 1)}{9} + C$$
Problem 4 — Decompose $\displaystyle \frac{x^2}{(x - 1)(x^2 + 4)}$

Find the partial fraction decomposition including the irreducible quadratic factor.

Show Answer

Answer:

The decomposition takes the form:

$$\frac{x^2}{(x - 1)(x^2 + 4)} = \frac{1}{5(x - 1)} + \frac{-x + 4}{5(x^2 + 4)}$$
Problem 5 — Evaluate $\displaystyle \int \frac{dx}{x^2 + 4x + 5}$

Complete the square and use an appropriate substitution.

Show Answer

Answer:

Complete the square: $x^2 + 4x + 5 = (x + 2)^2 + 1$. Use $u = x + 2$:

$$\int \frac{dx}{x^2 + 4x + 5} = \arctan(x + 2) + C$$

Study Tips

1. Always simplify the integrand algebraically before selecting a method.

2. For rational functions, long division must come first if the numerator degree is greater than or equal to the denominator degree.

3. When using trig substitution, draw a right triangle to make back-substitution easier.

4. Integration by parts often requires applying the formula more than once. Choose $u$ and $dv$ so that $\int v\,du$ is simpler than the original integral.

5. Practice recognizing patterns. With enough examples, you will intuitively know which method to try first.
