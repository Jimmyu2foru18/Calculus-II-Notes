Partial Fractions and Improper Integrals

Problem 1: Partial Fraction Decomposition

Task: Decompose (3x+5)/(x^2-4) into partial fractions.

Click to see the solution

Step 1: Factor the denominator

x^2 - 4 = (x+2)(x-2)

Step 2: Set up the decomposition

(3x+5)/((x+2)(x-2)) = A/(x+2) + B/(x-2)

Step 3: Clear denominators

3x + 5 = A(x-2) + B(x+2)

Step 4: Solve for A and B

Set x = 2: 3(2)+5 = A(0) + B(4) => 11 = 4B => B = 11/4

Set x = -2: 3(-2)+5 = A(-4) + B(0) => -1 = -4A => A = 1/4

Final Answer:

(3x+5)/(x^2-4) = 1/(4(x+2)) + 11/(4(x-2))

Problem 2: Improper Integrals

Task: Determine if integral from 1 to infinity of 1/x^2 dx converges or diverges.

Click to see the solution

Step 1: Set up as a limit

integral from 1 to infinity of 1/x^2 dx = lim(b->infinity) integral from 1 to b of x^(-2) dx

Step 2: Integrate

= lim(b->infinity) [-1/x] from 1 to b

Step 3: Evaluate the limit

= lim(b->infinity) (-1/b + 1) = 0 + 1 = 1

Final Answer:

The integral converges to 1
