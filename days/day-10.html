Partial Fractions with Repeated Factors

When the denominator contains a repeated factor $(x - r)^k$, the decomposition includes a term for each power from $1$ to $k$.

Repeated Linear Factors

For a factor $(x - r)^k$, write:

$$\frac{P(x)}{(x - r)^k} = \frac{A_1}{x - r} + \frac{A_2}{(x - r)^2} + \cdots + \frac{A_k}{(x - r)^k}$$

Example 1.1

Problem: Decompose $\displaystyle \frac{x^2 + 3x + 2}{(x + 1)^3}$.

Click to see the solution

Step 1:

Set up the decomposition for the repeated factor $(x + 1)^3$:

$$\frac{x^2 + 3x + 2}{(x + 1)^3} = \frac{A}{x + 1} + \frac{B}{(x + 1)^2} + \frac{C}{(x + 1)^3}$$

Step 2:

Clear denominators:

$$x^2 + 3x + 2 = A(x + 1)^2 + B(x + 1) + C$$

Step 3:

Expand and match coefficients:

$$x^2 + 3x + 2 = Ax^2 + (2A + B)x + (A + B + C)$$

Matching coefficients gives $A = 1$, $B = 1$, $C = 0$.

Final Answer:

$$\frac{x^2 + 3x + 2}{(x + 1)^3} = \frac{1}{x + 1} + \frac{1}{(x + 1)^2}$$

Partial Fractions with Irreducible Quadratics

When the denominator contains an irreducible quadratic factor $ax^2 + bx + c$, the numerator of that term must be linear: $Ax + B$.

Example 1.2

Problem: Decompose $\displaystyle \frac{x^2}{(x - 1)(x^2 + 4)}$.

Click to see the solution

Step 1:

Set up the decomposition with a linear factor and an irreducible quadratic:

$$\frac{x^2}{(x - 1)(x^2 + 4)} = \frac{A}{x - 1} + \frac{Bx + C}{x^2 + 4}$$

Step 2:

Clear denominators:

$$x^2 = A(x^2 + 4) + (Bx + C)(x - 1)$$

Step 3:

Expand and collect terms:

$$x^2 = Ax^2 + 4A + Bx^2 - Bx + Cx - C$$ $$= (A + B)x^2 + (-B + C)x + (4A - C)$$

Step 4:

Match coefficients: $A + B = 1$, $-B + C = 0$, $4A - C = 0$. Solving gives $A = \frac{1}{5}$, $B = \frac{4}{5}$, $C = \frac{4}{5}$.

Final Answer:

$$\frac{x^2}{(x - 1)(x^2 + 4)} = \frac{1}{5(x - 1)} + \frac{4x + 4}{5(x^2 + 4)}$$

Improper Integrals

An improper integral has either an infinite limit of integration or an integrand that is discontinuous on the interval. We evaluate these by taking limits.

Types of Improper Integrals

Type I: Infinite interval, e.g. $\displaystyle \int_1^{\infty} f(x)\,dx = \lim_{b \to \infty} \int_1^b f(x)\,dx$.

Type II: Discontinuous integrand, e.g. $\displaystyle \int_0^1 f(x)\,dx = \lim_{a \to 0^+} \int_a^1 f(x)\,dx$.

Convergence: If the limit exists (finite), the integral converges. Otherwise, it diverges.

Example 2.1

Problem: Determine whether $\displaystyle \int_1^{\infty} \frac{1}{x^2}\,dx$ converges or diverges.

Figure — Improper integral of $1/x^2$

The function $y = 1/x^2$ has a finite improper integral $\int_1^{\infty} x^{-2}\,dx = 1$.

Click to see the solution

Step 1:

Set up as a limit (Type I improper integral):

$$\int_1^{\infty} \frac{1}{x^2}\,dx = \lim_{b \to \infty} \int_1^b x^{-2}\,dx$$

Step 2:

Integrate:

$$\lim_{b \to \infty} \left[-\frac{1}{x}\right]_1^b = \lim_{b \to \infty} \left(-\frac{1}{b} + 1\right)$$

Step 3:

Evaluate the limit:

$$= 0 + 1 = 1$$

Final Answer:

The integral converges to $1$.

Example 2.2

Problem: Determine whether $\displaystyle \int_0^1 \frac{1}{x^{3/4}}\,dx$ converges or diverges.

Figure — Improper integral of $x^{-3/4}$ near $x=0$

The function $y = x^{-3/4}$ has a vertical asymptote at $x=0$ but the integral converges to 4.

Click to see the solution

Step 1:

Identify as Type II (discontinuity at $x = 0$). Set up as a limit:

$$\int_0^1 x^{-3/4}\,dx = \lim_{a \to 0^+} \int_a^1 x^{-3/4}\,dx$$

Step 2:

Integrate:

$$\lim_{a \to 0^+} \left[ \frac{x^{1/4}}{1/4} \right]_a^1 = \lim_{a \to 0^+} \left[ 4x^{1/4} \right]_a^1$$

Step 3:

Evaluate the limit:

$$= 4(1) - 4(0) = 4$$

Final Answer:

The integral converges to $4$.

Example 2.3

Problem: Determine whether $\displaystyle \int_1^{\infty} \frac{1}{x}\,dx$ converges or diverges.

Figure — Comparison of $1/x$ and $1/x^2$

The harmonic integral $\int_1^{\infty} \frac{1}{x}\,dx$ (blue) diverges, while $\int_1^{\infty} \frac{1}{x^2}\,dx$ (red) converges.

Click to see the solution

Step 1:

Set up as a limit:

$$\int_1^{\infty} \frac{1}{x}\,dx = \lim_{b \to \infty} \int_1^b \frac{1}{x}\,dx$$

Step 2:

Integrate:

$$\lim_{b \to \infty} [\ln|x|]_1^b = \lim_{b \to \infty} (\ln(b) - \ln(1)) = \lim_{b \to \infty} \ln(b)$$

Step 3:

Evaluate the limit:

$$= \infty$$

Final Answer:

The integral diverges.

Practice Problems

Problem 1 — Decompose $\displaystyle \frac{2x - 1}{x^2 - 5x + 6}$

Factor the denominator and find the partial fraction decomposition.

Show Answer

Answer:

Factor: $x^2 - 5x + 6 = (x - 2)(x - 3)$. The decomposition is:

$$\frac{2x - 1}{x^2 - 5x + 6} = \frac{3}{x - 2} - \frac{1}{x - 3}$$
Problem 2 — Evaluate $\displaystyle \int \frac{dx}{x^2\sqrt{4 - x^2}}$

Use trigonometric substitution.

Show Answer

Answer:

Use $x = 2\sin(\theta)$. The result is:

$$\int \frac{dx}{x^2\sqrt{4 - x^2}} = -\frac{\sqrt{4 - x^2}}{4x} + C$$
Problem 3 — Determine whether $\displaystyle \int_2^{\infty} \frac{1}{x(\ln x)^2}\,dx$ converges

Evaluate the improper integral.

Show Answer

Answer:

Let $u = \ln(x)$, $du = \frac{1}{x}\,dx$. When $x = 2$, $u = \ln(2)$. When $x \to \infty$, $u \to \infty$:

$$\int_2^{\infty} \frac{1}{x(\ln x)^2}\,dx = \lim_{b \to \infty} \int_{\ln(2)}^b \frac{1}{u^2}\,du = \lim_{b \to \infty} \left[-\frac{1}{u}\right]_{\ln(2)}^b = \frac{1}{\ln(2)}$$

The integral converges to $\frac{1}{\ln(2)}$.

Problem 4 — Determine whether $\displaystyle \int_0^3 \frac{1}{(x - 1)^{2/3}}\,dx$ converges

Note the discontinuity at $x = 1$.

Show Answer

Answer:

Split the integral at the discontinuity:

$$\int_0^3 \frac{1}{(x - 1)^{2/3}}\,dx = \lim_{a \to 1^-} \int_0^a (x - 1)^{-2/3}\,dx + \lim_{b \to 1^+} \int_b^3 (x - 1)^{-2/3}\,dx$$

Each integral evaluates to $3(x - 1)^{1/3}$, and both limits exist. The total is $3(2^{1/3}) + 3(2^{1/3}) = 6\sqrt[3]{2}$. The integral converges.

Problem 5 — Evaluate $\displaystyle \int \frac{2x + 3}{x^3 + x}\,dx$ using partial fractions

Factor the denominator and decompose before integrating.

Show Answer

Answer:

Factor: $x^3 + x = x(x^2 + 1)$. Decompose:

$$\frac{2x + 3}{x(x^2 + 1)} = \frac{3}{x} + \frac{-3x + 2}{x^2 + 1}$$

Integrate term by term:

$$\int \frac{2x + 3}{x^3 + x}\,dx = 3\ln|x| - \frac{3}{2}\ln(x^2 + 1) + 2\arctan(x) + C$$
Problem 6 — Determine whether $\displaystyle \int_0^{\infty} e^{-x^2}\,dx$ converges

Use a comparison test.

Show Answer

Answer:

For $x \geq 0$, $e^{-x^2} \leq e^{-x}$ (since $x^2 \geq x$ for $x \geq 1$ and the inequality holds near $0$ by continuity). Since $\int_0^{\infty} e^{-x}\,dx = 1$ converges, by the Comparison Test, $\int_0^{\infty} e^{-x^2}\,dx$ also converges.

In fact, $\int_0^{\infty} e^{-x^2}\,dx = \frac{\sqrt{\pi}}{2}$.

Study Tips

1. For Type I improper integrals, always write the limit explicitly before evaluating.

2. For Type II improper integrals with a single discontinuity, split the integral at the discontinuity and evaluate each limit separately.

3. Use the Comparison Test when direct integration is difficult. Compare with a known $p$-series or exponential integral.

4. When decomposing rational functions, always check that $\deg(P) < \deg(Q)$ first. If not, perform polynomial long division.

5. Memorize standard integrals like $\int \frac{1}{x^2 + a^2}\,dx = \frac{1}{a}\arctan\left(\frac{x}{a}\right) + C$ for partial fractions with quadratics.
