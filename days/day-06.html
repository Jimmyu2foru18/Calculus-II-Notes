Volumes by Shells and Motion

Volumes by Shells Method

The Shell Method is used to find the volume of a solid of revolution when the disk/washer method is difficult to apply.

Shell Method Formulas

  • Revolution about the y-axis: $V = 2\pi \int_a^b x \cdot f(x)\,dx$
  • Revolution about the y-axis (top-bottom): $V = 2\pi \int_a^b x[\text{top} - \text{bottom}]\,dx$
  • Revolution about the x-axis: $V = 2\pi \int_c^d y \cdot g(y)\,dy$
  • Revolution about the x-axis (right-left): $V = 2\pi \int_c^d y[\text{right} - \text{left}]\,dy$

Problem 1: Volume by Shells about the y-axis

Given: Region bounded by $y = x^2$, $y = 4$, and $x = 0$, revolved about the y-axis.

Click to see the solution

Step 1: Identify the bounds and functions

Find the intersection of $y = x^2$ and $y = 4$:

$$x^2 = 4 \implies x = \pm 2$$

Since $x \geq 0$, we have $x = 2$. The region extends from $x = 0$ to $x = 2$.

Step 2: Set up the shell integral

Using the shell method about the y-axis with vertical slices:

$$V = 2\pi \int_0^2 x \cdot (\text{top} - \text{bottom})\,dx$$

Here, $\text{top} = 4$ and $\text{bottom} = x^2$:

$$V = 2\pi \int_0^2 x(4 - x^2)\,dx$$

Step 3: Evaluate the integral

$$V = 2\pi \int_0^2 (4x - x^3)\,dx$$ $$V = 2\pi \left[2x^2 - \frac{x^4}{4}\right]_0^2$$

Step 4: Compute the bounds

$$V = 2\pi \left[\left(2(2)^2 - \frac{(2)^4}{4}\right) - \left(2(0)^2 - \frac{(0)^4}{4}\right)\right]$$ $$V = 2\pi \left[8 - 4\right]$$ $$V = 2\pi \cdot 4$$

Final Answer:

$$\boxed{V = 8\pi}$$

Problem 3: Volume by Shells about the x-axis

Given: Region bounded by $y = 4 - x^2$ and the x-axis, revolved about the x-axis using horizontal shells.

Click to see the solution

Step 1: Express x in terms of y

From $y = 4 - x^2$, we get $x^2 = 4 - y$, so $x = \sqrt{4-y}$ (right side).

Step 2: Set up the shell integral about the x-axis

Using horizontal shells (integrating with respect to $y$):

$$V = 2\pi \int_0^4 y \cdot (\text{right} - \text{left})\,dy$$

Here, $\text{right} = \sqrt{4-y}$ and $\text{left} = 0$:

$$V = 2\pi \int_0^4 y\sqrt{4-y}\,dy$$

Step 3: Use substitution to evaluate

Let $u = 4 - y$, then $du = -dy$ and $y = 4 - u$.

When $y = 0$, $u = 4$. When $y = 4$, $u = 0$.

$$V = 2\pi \int_4^0 (4-u)\sqrt{u}\,(-du)$$ $$V = 2\pi \int_0^4 (4-u)u^{1/2}\,du$$ $$V = 2\pi \int_0^4 (4u^{1/2} - u^{3/2})\,du$$

Step 4: Integrate

$$V = 2\pi \left[4 \cdot \frac{2}{3}u^{3/2} - \frac{2}{5}u^{5/2}\right]_0^4$$ $$V = 2\pi \left[\frac{8}{3}u^{3/2} - \frac{2}{5}u^{5/2}\right]_0^4$$

Step 5: Evaluate at bounds

$$V = 2\pi \left[\left(\frac{8}{3}(4)^{3/2} - \frac{2}{5}(4)^{5/2}\right) - 0\right]$$

Note: $4^{3/2} = 8$ and $4^{5/2} = 32$

$$V = 2\pi \left[\frac{8}{3} \cdot 8 - \frac{2}{5} \cdot 32\right]$$ $$V = 2\pi \left[\frac{64}{3} - \frac{64}{5}\right]$$ $$V = 2\pi \cdot 64 \cdot \left(\frac{1}{3} - \frac{1}{5}\right)$$ $$V = 128\pi \cdot \frac{5-3}{15}$$ $$V = 128\pi \cdot \frac{2}{15}$$

Final Answer:

$$\boxed{V = \frac{256\pi}{15}}$$

Motion: Position, Velocity, and Acceleration

The relationships between position $s(t)$, velocity $v(t)$, and acceleration $a(t)$ are:

  • $a(t) = v'(t) = s''(t)$
  • $v(t) = \int a(t)\,dt$
  • $s(t) = \int v(t)\,dt$

Problem 4: Motion on Earth

Given: Acceleration due to gravity $a(t) = -9.8$ m/s². Find $v(t)$ and $s(t)$.

Click to see the solution

Step 1: Find velocity

$$v(t) = \int a(t)\,dt = \int (-9.8)\,dt = -9.8t + C_1$$

Step 2: Find position

$$s(t) = \int v(t)\,dt = \int (-9.8t + C_1)\,dt = -4.9t^2 + C_1t + C_2$$

Note:

Without initial conditions, we cannot determine the constants $C_1$ and $C_2$.

Final Answer (with constants):

$$\boxed{v(t) = -9.8t + C_1}$$ $$\boxed{s(t) = -4.9t^2 + C_1t + C_2}$$

Problem 5: Motion with Initial Conditions

Given: $a(t) = t$, $v(0) = 0$, $s(0) = 100$. Find $v(t)$ and $s(t)$.

Click to see the solution

Step 1: Find velocity

$$v(t) = \int a(t)\,dt = \int t\,dt = \frac{t^2}{2} + C$$

Apply the initial condition $v(0) = 0$:

$$v(0) = \frac{(0)^2}{2} + C = 0 \implies C = 0$$

Therefore:

$$v(t) = \frac{t^2}{2}$$

Step 2: Find position

$$s(t) = \int v(t)\,dt = \int \frac{t^2}{2}\,dt = \frac{t^3}{6} + D$$

Apply the initial condition $s(0) = 100$:

$$s(0) = \frac{(0)^3}{6} + D = 100 \implies D = 100$$

Therefore:

$$s(t) = \frac{t^3}{6} + 100$$

Final Answer:

$$\boxed{v(t) = \frac{t^2}{2} \text{ m/s}}$$ $$\boxed{s(t) = \frac{t^3}{6} + 100 \text{ meters}}$$

Problem 6: Motion with Exponential Acceleration

Given: $a(t) = e^{-t}$, $v(0) = 0$, $s(0) = 0$. Find $v(t)$ and $s(t)$.

Click to see the solution

Step 1: Find velocity

$$v(t) = \int a(t)\,dt = \int e^{-t}\,dt = -e^{-t} + C$$

Apply the initial condition $v(0) = 0$:

$$v(0) = -e^{0} + C = 0 \implies -1 + C = 0 \implies C = 1$$

Therefore:

$$v(t) = -e^{-t} + 1 = 1 - e^{-t}$$

Step 2: Find position

$$s(t) = \int v(t)\,dt = \int (1 - e^{-t})\,dt = t + e^{-t} + D$$

Apply the initial condition $s(0) = 0$:

$$s(0) = 0 + e^{0} + D = 0 \implies 1 + D = 0 \implies D = -1$$

Therefore:

$$s(t) = t + e^{-t} - 1$$

Final Answer:

$$\boxed{v(t) = 1 - e^{-t}}$$ $$\boxed{s(t) = t + e^{-t} - 1}$$

Problem 7: Physics Application - Spaceship Velocity

Given: $v(t) = 100(e^{t/10} - 1)$. When does the spaceship reach velocity 100 m/s?

Click to see the solution

Step 1: Set up the equation

$$v(t) = 100$$ $$100(e^{t/10} - 1) = 100$$

Step 2: Solve for t

$$e^{t/10} - 1 = 1$$ $$e^{t/10} = 2$$ $$\frac{t}{10} = \ln(2)$$ $$t = 10\ln(2)$$

Final Answer:

$$\boxed{t = 10\ln(2) \approx 6.93 \text{ seconds}}$$
