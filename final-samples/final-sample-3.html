Problem 1: Trig Substitution

Evaluate: $\int \frac{x^3}{\sqrt{4-x^2}}\,dx$

Click to see the solution

Let $x = 2\sin(\theta)$, $dx = 2\cos(\theta)\,d\theta$

$x^3 = 8\sin^3(\theta)$, $\sqrt{4-x^2} = 2\cos(\theta)$

$$= \int \frac{8\sin^3(\theta) \cdot 2\cos(\theta)\,d\theta}{2\cos(\theta)}$$ $$= 8\int \sin^3(\theta)\,d\theta$$

Use $\sin^2(\theta) = 1-\cos^2(\theta)$ and $u = \cos(\theta)$:

$$= 8\int (1-u^2)(-du) = -8\left(u - \frac{u^3}{3}\right) + C$$

Back-substitute: $\cos(\theta) = \frac{\sqrt{4-x^2}}{2}$

$$= -4\sqrt{4-x^2} + \frac{(4-x^2)^{3/2}}{3} + C$$

Problem 2: Series Convergence with Ratio Test

Task: Test $\sum_{n=1}^{\infty} \frac{n^2}{3^n}$ for convergence

Click to see the solution $$\rho = \lim_{n\to\infty} \frac{(n+1)^2/3^{n+1}}{n^2/3^n}$$ $$= \lim_{n\to\infty} \frac{(n+1)^2}{3n^2}$$ $$= \lim_{n\to\infty} \frac{1}{3}\left(1 + \frac{1}{n}\right)^2$$ $$= \frac{1}{3}$$

Since $\rho = \frac{1}{3} < 1$, the series converges by the Ratio Test.

Problem 3: Parametric Curves

Task: Find the slope of the tangent line to the curve $x = \cos(t)$, $y = \sin(t)$ at $t = \pi/4$

Click to see the solution

$\frac{dx}{dt} = -\sin(t)$, $\frac{dy}{dt} = \cos(t)$

Slope: $\frac{dy}{dx} = \frac{dy/dt}{dx/dt} = \frac{\cos(t)}{-\sin(t)} = -\cot(t)$

At $t = \pi/4$:

$$m = -\cot\left(\frac{\pi}{4}\right) = -1$$

The tangent line has slope $-1$.
