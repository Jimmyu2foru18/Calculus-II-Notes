Problem 1: Partial Fractions

Evaluate: $\int \frac{3x+5}{x^2-4}\,dx$

Decompose: $\frac{3x+5}{(x-2)(x+2)} = \frac{A}{x-2} + \frac{B}{x+2}$

$3x+5 = A(x+2) + B(x-2)$

Set $x = 2$: $11 = 4B \implies B = \frac{11}{4}$

Set $x = -2$: $-1 = -4A \implies A = \frac{1}{4}$

$$= \int\left(\frac{1/4}{x-2} + \frac{11/4}{x+2}\right)dx$$ $$= \frac{1}{4}\ln|x-2| + \frac{11}{4}\ln|x+2| + C$$

Problem 2: Taylor Series

Task: Find the Maclaurin series for $f(x) = \frac{1}{1-x}$

This is a geometric series with first term $a = 1$ and ratio $r = x$:

$$\frac{1}{1-x} = \sum_{n=0}^{\infty} x^n = 1 + x + x^2 + x^3 + \cdots$$

Converges for $|x| < 1$

Problem 3: Polar Area

Task: Find the area enclosed by the cardioid $r = 1 + \cos(\theta)$

$$A = \frac{1}{2}\int_0^{2\pi} (1+\cos(\theta))^2\,d\theta$$

Expand: $(1+\cos(\theta))^2 = 1 + 2\cos(\theta) + \cos^2(\theta)$

$$= 1 + 2\cos(\theta) + \frac{1+\cos(2\theta)}{2}$$

$$= \frac{3}{2} + 2\cos(\theta) + \frac{1}{2}\cos(2\theta)$$

$$A = \frac{1}{2}\left[\frac{3\theta}{2} + 2\sin(\theta) + \frac{\sin(2\theta)}{4}\right]_0^{2\pi}$$

$$= \frac{1}{2}(3\pi) = \frac{3\pi}{2}$$
