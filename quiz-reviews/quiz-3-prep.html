Review these key topics before taking Quiz 3.

Key Topics

  • Fundamental Theorem of Calculus Part I and Part II
  • Differentiation of integrals with variable limits
  • Mean Value Theorem for Integrals
  • Area between curves

Quick Reference

  • FTC Part I: $\frac{d}{dx}\int_a^x f(t)\,dt = f(x)$
  • FTC Part II: $\int_a^b f(x)\,dx = F(b) - F(a)$
  • Variable upper limit: $\frac{d}{dx}\int_a^{g(x)} f(t)\,dt = f(g(x))\cdot g'(x)$
  • MVTI: $f(c) = \frac{1}{b-a}\int_a^b f(x)\,dx$
  • Area: $A = \int_a^b [f(x) - g(x)]\,dx$

Practice Checklist

  • Apply FTC to evaluate definite integrals
  • Differentiate integrals with variable limits
  • Find average values using MVTI
  • Calculate areas between curves
