Review these key topics before taking Quiz 3.

Key Topics

  • Fundamental Theorem of Calculus Part I and Part II
  • Differentiation of integrals with variable limits
  • Mean Value Theorem for Integrals
  • Area between curves

Quick Reference

  • FTC Part I: $\frac{d}{dx}\int_a^x f(t)\,dt = f(x)$
  • FTC Part II: $\int_a^b f(x)\,dx = F(b) - F(a)$
  • Variable upper limit: $\frac{d}{dx}\int_a^{g(x)} f(t)\,dt = f(g(x))\cdot g'(x)$
  • MVTI: $f(c) = \frac{1}{b-a}\int_a^b f(x)\,dx$
  • Area: $A = \int_a^b [f(x) - g(x)]\,dx$

Practice Problems

Problem 1: Evaluate $\int_0^2 (3x^2 + 2x)\,dx$ using FTC Part II.

Click to see the solution
Step 1: Find the antiderivative: $F(x) = x^3 + x^2$.
Step 2: Apply FTC Part II:
$F(2) - F(0) = (8 + 4) - (0 + 0)$
Final Answer:
$$12$$

Problem 2: Find $\frac{d}{dx}\int_0^x \sin(t^2)\,dt$.

Click to see the solution
Step 1: Apply FTC Part I: $\frac{d}{dx}\int_a^x f(t)\,dt = f(x)$.
Final Answer:
$$\sin(x^2)$$

Problem 3: Find $\frac{d}{dx}\int_1^{x^2} e^t\,dt$.

Click to see the solution
Step 1: Apply the variable upper limit rule: $\frac{d}{dx}\int_a^{g(x)} f(t)\,dt = f(g(x))\cdot g'(x)$.
Step 2: Here $f(t) = e^t$, $g(x) = x^2$, and $g'(x) = 2x$.
Final Answer:
$$e^{x^2} \cdot 2x$$

Problem 4: Find the average value of $f(x) = x^2$ on $[1, 3]$ using the Mean Value Theorem for Integrals.

Click to see the solution
Step 1: Compute the integral: $\int_1^3 x^2\,dx = \left[\frac{x^3}{3}\right]_1^3 = \frac{27}{3} - \frac{1}{3} = \frac{26}{3}$.
Step 2: Apply the average value formula:
$f_{\text{avg}} = \frac{1}{b-a}\int_a^b f(x)\,dx = \frac{1}{2} \cdot \frac{26}{3}$
Final Answer:
$$\frac{13}{3}$$
