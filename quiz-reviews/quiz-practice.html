Problem 1: u-Substitution

Evaluate: $\int x e^{x^2}\,dx$

Click to see the solution

Let $u = x^2$, $du = 2x\,dx$, so $x\,dx = \frac{du}{2}$

$$= \int e^u \cdot \frac{du}{2}$$ $$= \frac{1}{2}e^u + C$$ $$= \frac{1}{2}e^{x^2} + C$$

Problem 2: Trig Integral

Evaluate: $\int_0^{\pi} \sin^2(x)\,dx$

Click to see the solution

Use the identity $\sin^2(x) = \frac{1-\cos(2x)}{2}$

$$= \int_0^{\pi} \frac{1-\cos(2x)}{2}\,dx$$ $$= \frac{1}{2}\left[x - \frac{\sin(2x)}{2}\right]_0^{\pi}$$ $$= \frac{1}{2}(\pi - 0)$$ $$= \frac{\pi}{2}$$

Problem 3: Area Between Curves

Task: Find the area between $y = x^2$ and $y = x+2$

Click to see the solution

Intersection points: $x^2 = x+2 \implies x^2-x-2 = 0 \implies (x+1)(x-2) = 0$

So $x = -1$ and $x = 2$

$$A = \int_{-1}^2 [(x+2) - x^2]\,dx$$ $$= \left[\frac{x^2}{2} + 2x - \frac{x^3}{3}\right]_{-1}^2$$ $$= \left(2 + 4 - \frac{8}{3}\right) - \left(\frac{1}{2} - 2 + \frac{1}{3}\right)$$ $$= \frac{10}{3} - \left(-\frac{7}{6}\right)$$ $$= \frac{27}{6} = \frac{9}{2}$$
