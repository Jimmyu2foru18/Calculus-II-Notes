Example 1: FTC Part I

Task: If $F(x) = \int_0^x f(t)\,dt$, find $F'(x)$.

Click to see the solution

Step 1:

Apply FTC Part I directly:

Final Answer:

$$F'(x) = f(x)$$

Example 2: Chain Rule with FTC

Task: Find $\frac{d}{dx}\int_0^{x^2} \sin(t^2)\,dt$

Click to see the solution

Step 1:

Identify the upper limit function $g(x) = x^2$, so $g'(x) = 2x$

Step 2:

Apply the chain rule for variable upper limits:

$$= \sin((x^2)^2) \cdot 2x$$

Final Answer:

$$2x\sin(x^4)$$

Example 3: Area Between Curves

Task: Find the area between $f(x) = \sin(2x)$ and the x-axis from $x=0$ to $x=\pi$.

Click to see the solution

Step 1:

Split at $x = \pi/2$ where $\sin(2x)$ changes sign:

$$A = \int_0^{\pi/2} \sin(2x)\,dx + \int_{\pi/2}^{\pi} (-\sin(2x))\,dx$$

Step 2:

Let $u = 2x$, $du = 2dx$ in both integrals:

$$= \frac{1}{2}\int_0^{\pi} \sin(u)\,du + \frac{1}{2}\int_{\pi}^{2\pi} \sin(u)\,du$$

Step 3:

Evaluate both integrals:

$$= \frac{1}{2}[-\cos(u)]_0^{\pi} + \frac{1}{2}[-\cos(u)]_{\pi}^{2\pi}$$

Final Answer:

$$= \frac{1}{2}(1+1) + \frac{1}{2}(1+1) = 2$$

Problem 2

Find the area: Between $y = x^2$ and $y = 2x+1$

Show Answer

Answer:

Intersection at $x = 1$. Area $= \int_0^1 [(2x+1) - x^2]\,dx = \left[x^2+x-\frac{x^3}{3}\right]_0^1 = \frac{5}{3}$

Problem 3

State and explain: The Mean Value Theorem for Integrals

Show Answer

Answer:

If $f$ is continuous on $[a,b]$, there exists $c \in [a,b]$ such that $f(c) = \frac{1}{b-a}\int_a^b f(x)\,dx$. This means $f$ attains its average value somewhere on the interval.
