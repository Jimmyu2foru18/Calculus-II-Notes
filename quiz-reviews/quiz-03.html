Key Formulas at a Glance

  • FTC Part I: $\frac{d}{dx}\int_a^x f(t)\,dt = f(x)$
  • FTC Part II: $\int_a^b f(x)\,dx = F(b) - F(a)$
  • Chain Rule: $\frac{d}{dx}\int_a^{g(x)} f(t)\,dt = f(g(x))\cdot g'(x)$
  • Mean Value Theorem for Integrals: $f(c) = \frac{1}{b-a}\int_a^b f(x)\,dx$
  • Area Between Curves: $A = \int_a^b [f(x) - g(x)]\,dx$

Worked Examples

Example 1: FTC Part I

Task: If $F(x) = \int_0^x f(t)\,dt$, find $F'(x)$.

Click to see the solution $$F'(x) = f(x)$$

Example 2: Chain Rule with FTC

Task: Find $\frac{d}{dx}\int_0^{x^2} \sin(t^2)\,dt$

Click to see the solution

Upper limit: $g(x) = x^2$, so $g'(x) = 2x$

$$= \sin((x^2)^2) \cdot 2x$$ $$= 2x\sin(x^4)$$

Example 3: Area Between Curves

Task: Find the area between $f(x) = \sin(2x)$ and the x-axis from $x=0$ to $x=\pi$.

Click to see the solution

Split at $x = \pi/2$ where $\sin(2x)$ changes sign:

$$A = \int_0^{\pi/2} \sin(2x)\,dx + \int_{\pi/2}^{\pi} (-\sin(2x))\,dx$$

Let $u = 2x$, $du = 2dx$ in both integrals:

$$= \frac{1}{2}\int_0^{\pi} \sin(u)\,du + \frac{1}{2}\int_{\pi}^{2\pi} \sin(u)\,du$$ $$= \frac{1}{2}[-\cos(u)]_0^{\pi} + \frac{1}{2}[-\cos(u)]_{\pi}^{2\pi}$$ $$= \frac{1}{2}(1+1) + \frac{1}{2}(1+1)$$ $$= 2$$
