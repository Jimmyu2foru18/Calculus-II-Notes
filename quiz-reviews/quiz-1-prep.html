Key Topics

Quick Reference

  • $\int x^n\,dx = \frac{x^{n+1}}{n+1} + C$
  • $\int e^{ax}\,dx = \frac{1}{a}e^{ax} + C$
  • $\int \sin(ax)\,dx = -\frac{1}{a}\cos(ax) + C$
  • $\int \cos(ax)\,dx = \frac{1}{a}\sin(ax) + C$

Practice Problems

Problem 1: Evaluate $\int 2x\sqrt{x^2+1}\,dx$ using u-substitution.

Click to see the solution
Step 1: Let $u = x^2 + 1$, then $du = 2x\,dx$.
Step 2: Rewrite the integral:
$\int \sqrt{u}\,du = \int u^{1/2}\,du$
Step 3: Integrate:
$\frac{u^{3/2}}{3/2} + C = \frac{2}{3}u^{3/2} + C$
Final Answer:
$$\frac{2}{3}(x^2+1)^{3/2} + C$$

Problem 2: Evaluate $\int e^{3x}\,dx$.

Click to see the solution
Step 1: Use the exponential integration formula with $a = 3$.
Final Answer:
$$\frac{1}{3}e^{3x} + C$$

Problem 3: Evaluate $\int \sin(2x)\,dx$.

Click to see the solution
Step 1: Use the trig integration formula with $a = 2$.
Final Answer:

Problem 4: Find the area between $f(x) = x^2$ and $g(x) = x$ on the interval $[0, 1]$.

Click to see the solution
Step 1: Determine which function is on top. On $[0,1]$, $x > x^2$.
Step 2: Set up the area integral:
$A = \int_0^1 (x - x^2)\,dx$
Step 3: Integrate:
$\left[\frac{x^2}{2} - \frac{x^3}{3}\right]_0^1 = \frac{1}{2} - \frac{1}{3}$
Final Answer:
$$\frac{1}{6}$$
