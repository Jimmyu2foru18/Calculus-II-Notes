Key Formulas

FormulaDescription
$\int x^n\,dx = \frac{x^{n+1}}{n+1} + C$Power Rule ($n \neq -1$)
$\int e^{ax}\,dx = \frac{1}{a}e^{ax} + C$Exponential
$\int \sin(ax)\,dx = -\frac{1}{a}\cos(ax) + C$Sine
$\int \cos(ax)\,dx = \frac{1}{a}\sin(ax) + C$Cosine

Worked Examples

Example 1: u-Substitution

Evaluate: $\int 2x\sqrt{x^2+1}\,dx$

Click to see the solution

Step 1:

Let $u = x^2 + 1$, then $du = 2x\,dx$.

Step 2:

Rewrite the integral:

$\int \sqrt{u}\,du = \int u^{1/2}\,du$

Step 3:

Integrate:

$\frac{u^{3/2}}{3/2} + C = \frac{2}{3}u^{3/2} + C$

Final Answer:

$$\frac{2}{3}(x^2+1)^{3/2} + C$$

Example 2: Exponential Integration

Evaluate: $\int e^{3x}\,dx$

Click to see the solution

Step 1:

Use the exponential integration formula with $a = 3$.

Final Answer:

$$\frac{1}{3}e^{3x} + C$$

Example 3: Trig Integration

Evaluate: $\int \sin(2x)\,dx$

Click to see the solution

Step 1:

Use the trig integration formula with $a = 2$.

Final Answer:

$$-\frac{1}{2}\cos(2x) + C$$

Example 4: Area Between Curves

Find the area: Between $f(x) = x^2$ and $g(x) = x$ on $[0, 1]$

Click to see the solution

Step 1:

Determine which function is on top. On $[0,1]$, $x > x^2$.

Step 2:

Set up the area integral:

$A = \int_0^1 (x - x^2)\,dx$

Step 3:

Integrate and evaluate:

$\left[\frac{x^2}{2} - \frac{x^3}{3}\right]_0^1 = \frac{1}{2} - \frac{1}{3}$

Final Answer:

$$\frac{1}{6}$$
