Review these key topics before taking Quiz 2.

Key Topics

  • Advanced u-substitution
  • Trigonometric substitution
  • Riemann sums and summation notation
  • Basic series concepts

Quick Reference

  • $\sum_{k=1}^n k = \frac{n(n+1)}{2}$
  • $\sum_{k=1}^n k^2 = \frac{n(n+1)(2n+1)}{6}$
  • $\Delta x = \frac{b-a}{n}$
  • $x_i = a + i\Delta x$
  • $\sqrt{a^2-x^2}$: use $x = a\sin(\theta)$
  • $\sqrt{a^2+x^2}$: use $x = a\tan(\theta)$

Practice Checklist

  • Practice trig substitution problems
  • Review summation formulas
  • Calculate left and right Riemann sums
  • Work through series basic problems
