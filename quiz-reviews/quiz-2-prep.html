Practice Problems

Problem 1: Evaluate $\int \sqrt{9-x^2}\,dx$ using trigonometric substitution.

Click to see the solution
Step 1: Let $x = 3\sin(\theta)$, so $dx = 3\cos(\theta)\,d\theta$ and $\sqrt{9-x^2} = 3\cos(\theta)$.
Step 2: Rewrite the integral:
$\int 3\cos(\theta) \cdot 3\cos(\theta)\,d\theta = \int 9\cos^2(\theta)\,d\theta$
Step 3: Use $\cos^2(\theta) = \frac{1+\cos(2\theta)}{2}$:
$9\int \frac{1+\cos(2\theta)}{2}\,d\theta = \frac{9}{2}\left(\theta + \frac{\sin(2\theta)}{2}\right) + C$
Final Answer:
$$\frac{9}{2}\arcsin\left(\frac{x}{3}\right) + \frac{x}{2}\sqrt{9-x^2} + C$$

Problem 2: Evaluate $\int_0^2 (x^2+1)\,dx$ using a left Riemann sum with $n=4$ subintervals.

Click to see the solution
Step 1: Compute $\Delta x = \frac{2-0}{4} = \frac{1}{2}$.
Step 2: The left endpoints are $x_0 = 0$, $x_1 = 0.5$, $x_2 = 1$, $x_3 = 1.5$.
Step 3: Evaluate $f(x)$ at each left endpoint:
$f(0)=1$, $f(0.5)=1.25$, $f(1)=2$, $f(1.5)=3.25$
Step 4: Compute the sum:
$L_4 = \frac{1}{2}(1 + 1.25 + 2 + 3.25) = \frac{1}{2}(7.5) = 3.75$
Final Answer:
$$3.75$$

Problem 3: Find $\sum_{k=1}^{10} k^2$ using a summation formula.

Click to see the solution
Step 1: Use the formula $\sum_{k=1}^n k^2 = \frac{n(n+1)(2n+1)}{6}$ with $n=10$.
Step 2: Substitute:
$\frac{10(11)(21)}{6} = \frac{2310}{6}$
Final Answer:
$$385$$

Problem 4: Evaluate $\int x\cos(x^2)\,dx$ using u-substitution.

Click to see the solution
Step 1: Let $u = x^2$, then $du = 2x\,dx$, so $x\,dx = \frac{1}{2}\,du$.
Step 2: Rewrite the integral:
$\int \cos(u) \cdot \frac{1}{2}\,du = \frac{1}{2}\int \cos(u)\,du$
Step 3: Integrate:
$\frac{1}{2}\sin(u) + C$
Final Answer:
$$\frac{1}{2}\sin(x^2) + C$$
