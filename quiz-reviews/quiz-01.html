Key Formulas at a Glance

  • $\int x^n\,dx = \frac{x^{n+1}}{n+1} + C$ for $n \neq -1$
  • $\int e^{ax}\,dx = \frac{1}{a}e^{ax} + C$
  • $\int \frac{1}{x}\,dx = \ln|x| + C$
  • $\int \sin(ax)\,dx = -\frac{1}{a}\cos(ax) + C$
  • $\int \cos(ax)\,dx = \frac{1}{a}\sin(ax) + C$
  • $\int \sec^2(ax)\,dx = \frac{1}{a}\tan(ax) + C$
  • $\int \frac{1}{\sqrt{a^2-x^2}}\,dx = \sin^{-1}\left(\frac{x}{a}\right) + C$

Worked Examples

Example 1: Basic u-Substitution

Evaluate: $\int (2x^2+1)\,dx$

Click to see the solution
$$= 2\int x^2\,dx + \int 1\,dx$$ $$= 2\cdot\frac{x^3}{3} + x + C$$ $$= \frac{2x^3}{3} + x + C$$

Example 2: Exponential Integration

Evaluate: $\int e^{3x}\,dx$

Click to see the solution

Let $u = 3x$, $du = 3\,dx$, $dx = \frac{du}{3}$

$$= \int e^u \cdot \frac{du}{3}$$ $$= \frac{1}{3}e^u + C$$ $$= \frac{1}{3}e^{3x} + C$$

Example 3: Logarithmic Integration

Evaluate: $\int \frac{3x+2}{x^2+1}\,dx$

Click to see the solution
$$= \int\frac{3x}{x^2+1}\,dx + \int\frac{2}{x^2+1}\,dx$$

First integral: let $u = x^2+1$, $du = 2x\,dx$

$$= \frac{3}{2}\ln(x^2+1) + 2\tan^{-1}(x) + C$$
