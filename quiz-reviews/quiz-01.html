Key Formulas

FormulaDescription
$\int x^n\,dx = \frac{x^{n+1}}{n+1} + C$Power Rule ($n \neq -1$)
$\int e^{ax}\,dx = \frac{1}{a}e^{ax} + C$Exponential
$\int \frac{1}{x}\,dx = \ln|x| + C$Natural Log
$\int \sin(ax)\,dx = -\frac{1}{a}\cos(ax) + C$Sine
$\int \cos(ax)\,dx = \frac{1}{a}\sin(ax) + C$Cosine
$\int \sec^2(ax)\,dx = \frac{1}{a}\tan(ax) + C$Secant Squared
$\int \frac{1}{\sqrt{a^2-x^2}}\,dx = \sin^{-1}\left(\frac{x}{a}\right) + C$Inverse Sine

Worked Examples

Example 1: Basic u-Substitution

Evaluate: $\int (2x^2+1)\,dx$

Click to see the solution

Step 1:

Apply linearity of integration:

$$= 2\int x^2\,dx + \int 1\,dx$$

Step 2:

Integrate each term using the power rule:

$$= 2\cdot\frac{x^3}{3} + x + C$$

Final Answer:

$$\frac{2x^3}{3} + x + C$$

Example 2: Exponential Integration

Evaluate: $\int e^{3x}\,dx$

Click to see the solution

Step 1:

Let $u = 3x$, $du = 3\,dx$, $dx = \frac{du}{3}$

Step 2:

Substitute into the integral:

$$= \int e^u \cdot \frac{du}{3}$$

Step 3:

Integrate and back-substitute:

$$= \frac{1}{3}e^u + C$$

Final Answer:

$$\frac{1}{3}e^{3x} + C$$

Example 3: Logarithmic Integration

Evaluate: $\int \frac{3x+2}{x^2+1}\,dx$

Click to see the solution

Step 1:

Split the integral into two parts:

$$= \int\frac{3x}{x^2+1}\,dx + \int\frac{2}{x^2+1}\,dx$$

Step 2:

First integral: let $u = x^2+1$, $du = 2x\,dx$

Final Answer:

$$\frac{3}{2}\ln(x^2+1) + 2\tan^{-1}(x) + C$$
