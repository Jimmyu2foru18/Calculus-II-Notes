Key Formulas at a Glance

  • $\sum_{k=1}^n k = \frac{n(n+1)}{2}$
  • $\sum_{k=1}^n k^2 = \frac{n(n+1)(2n+1)}{6}$
  • $\sum_{k=1}^n k^3 = \left[\frac{n(n+1)}{2}\right]^2$
  • Riemann Sum: $L_n = \sum_{i=0}^{n-1} f(x_i)\Delta x$
  • Riemann Sum: $R_n = \sum_{i=1}^{n} f(x_i)\Delta x$
  • $\Delta x = \frac{b-a}{n}$
  • $x_i = a + i\Delta x$

Worked Examples

Example 1: Trig Substitution

Evaluate: $\int \sin(x)\cos^2(x)\,dx$

Let $u = \cos(x)$, $du = -\sin(x)\,dx$, so $\sin(x)\,dx = -du$

$$= \int u^2(-du)$$ $$= -\frac{u^3}{3} + C$$ $$= -\frac{\cos^3(x)}{3} + C$$

Example 2: Exponential with Trig

Evaluate: $\int \sec^2(x)e^{\tan(x)}\,dx$

Let $u = \tan(x)$, $du = \sec^2(x)\,dx$

$$= \int e^u\,du$$ $$= e^u + C$$ $$= e^{\tan(x)} + C$$

Example 3: Summation

Task: Evaluate $\sum_{k=1}^{1000} (2k^2-3k)$

$$= 2\sum_{k=1}^{1000} k^2 - 3\sum_{k=1}^{1000} k$$ $$= 2\cdot\frac{1000(1001)(2001)}{6} - 3\cdot\frac{1000(1001)}{2}$$ $$= 2\cdot 333833500 - 3\cdot 500500$$ $$= 667667000 - 1501500$$ $$= 666165500$$

Example 4: Riemann Sums

Task: Approximate $\int_1^6 (x+1)\,dx$ with $n=5$

$\Delta x = \frac{6-1}{5} = 1$

Left Sum: $L_5 = 1\cdot(2+3+4+5+6) = 20$

Right Sum: $R_5 = 1\cdot(3+4+5+6+7) = 25$
