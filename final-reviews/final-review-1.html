Key Formulas at a Glance

  • Integration by Parts: $\int u\,dv = uv - \int v\,du$
  • u-Substitution: $\int f(g(x))g'(x)\,dx = \int f(u)\,du$
  • Partial Fractions: $\frac{1}{(x-a)(x-b)} = \frac{A}{x-a} + \frac{B}{x-b}$
  • Geometric Series: $\sum_{n=0}^{\infty} ar^n = \frac{a}{1-r}$ for $|r| < 1$
  • p-Series: $\sum_{n=1}^{\infty} \frac{1}{n^p}$ converges if $p > 1$

Worked Examples

Example 1: Integration by Parts

Evaluate: $\int x\ln(x)\,dx$

Let $u = \ln(x)$, $dv = x\,dx$

$du = \frac{1}{x}\,dx$, $v = \frac{x^2}{2}$

$$= \frac{x^2}{2}\ln(x) - \int \frac{x^2}{2}\cdot\frac{1}{x}\,dx$$ $$= \frac{x^2}{2}\ln(x) - \frac{1}{2}\int x\,dx$$ $$= \frac{x^2}{2}\ln(x) - \frac{x^2}{4} + C$$

Example 2: Partial Fractions

Evaluate: $\int \frac{1}{x^2-1}\,dx$

$$\frac{1}{x^2-1} = \frac{1}{(x-1)(x+1)} = \frac{1/2}{x-1} - \frac{1/2}{x+1}$$ $$= \frac{1}{2}\ln|x-1| - \frac{1}{2}\ln|x+1| + C$$ $$= \frac{1}{2}\ln\left|\frac{x-1}{x+1}\right| + C$$

Example 3: Power Series

Task: Find the interval of convergence for $\sum_{n=0}^{\infty} x^n$

Apply the Ratio Test:

$$\rho = \lim_{n\to\infty} \frac{|x|^{n+1}}{|x|^n} = |x|$$

Converges when $|x| < 1$

At $x = 1$: $\sum 1$ diverges

At $x = -1$: $\sum (-1)^n$ diverges

Interval of Convergence: $(-1, 1)$
