Key Formulas at a Glance

  • $\sqrt{a^2-x^2}$: use $x = a\sin(\theta)$
  • $\sqrt{a^2+x^2}$: use $x = a\tan(\theta)$
  • $\sqrt{x^2-a^2}$: use $x = a\sec(\theta)$
  • $\sin^2(x) = \frac{1-\cos(2x)}{2}$
  • $\cos^2(x) = \frac{1+\cos(2x)}{2}$
  • $\int \tan(\theta)\,d\theta = \ln|\sec(\theta)| + C$
  • $\int \sec(\theta)\,d\theta = \ln|\sec(\theta)+\tan(\theta)| + C$

Worked Examples

Example 1: Basic Trig Substitution

Evaluate: $\int \frac{dx}{\sqrt{4-x^2}}$

Let $x = 2\sin(\theta)$, $dx = 2\cos(\theta)\,d\theta$

$\sqrt{4-x^2} = \sqrt{4-4\sin^2(\theta)} = 2\cos(\theta)$

$$= \int \frac{2\cos(\theta)\,d\theta}{2\cos(\theta)}$$ $$= \int d\theta = \theta + C$$ $$= \sin^{-1}\left(\frac{x}{2}\right) + C$$

Example 2: Complex Trig Substitution

Evaluate: $\int \frac{x^3\,dx}{\sqrt{4-x^2}}$

Let $x = 2\sin(\theta)$, $dx = 2\cos(\theta)\,d\theta$

$x^3 = 8\sin^3(\theta)$, $\sqrt{4-x^2} = 2\cos(\theta)$

$$= \int \frac{8\sin^3(\theta) \cdot 2\cos(\theta)\,d\theta}{2\cos(\theta)}$$ $$= 8\int \sin^3(\theta)\,d\theta$$

Use $\sin^2(\theta) = 1-\cos^2(\theta)$ and $u = \cos(\theta)$:

$$= 8\int (1-u^2)(-du) = 8\left(\frac{u^3}{3} - u\right) + C$$

Back-substitute: $\cos(\theta) = \frac{\sqrt{4-x^2}}{2}$

$$= \frac{(4-x^2)^{3/2}}{3} - 4\sqrt{4-x^2} + C$$
